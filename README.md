# Géssica Carneiro — Landing Page Institucional

Landing page premium e responsiva para a clínica Géssica Carneiro Estética Avançada, em Lagoa Santa/MG.

## Estrutura
- `index.html` — conteúdo e estrutura da página
- `styles.css` — identidade visual, responsividade e animações
- `script.js` — menu mobile, animações e configuração do WhatsApp

## WhatsApp
O número fica centralizado no início do arquivo `script.js`:

```js
const WHATSAPP_NUMBER = "5531997078109";
```

**Importante:** confirme o número oficial da clínica antes da publicação final.

## Imagens oficiais
A primeira versão usa uma composição gráfica premium no hero para não utilizar fotos de terceiros. O próximo refinamento recomendado é inserir fotos profissionais da Géssica, da clínica e de atendimentos autorizados.

## Publicação
A página é estática e pode ser publicada no GitHub Pages, Netlify, Vercel ou hospedagem tradicional sem etapa de build.
